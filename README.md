# Gestion Obion — starter

Starter initial de l'application de gestion du Groupe Scout Obion.

Cette première maquette contient une page d'accueil mobile et les rubriques prévues : jeunes, chefs, présences, cotisations, activités, finances, progression et documents PDF.

Important : cette maquette ne sauvegarde pas encore les données en ligne et ne réalise pas encore l'import Excel ni les exports PDF. Nous ajouterons et testerons ces fonctions progressivement.
